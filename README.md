## 💻 Cara Menjalankan Secara Lokal

### Menggunakan Laragon (Disarankan)
1. Letakkan folder ini di `c:\laragon\Portofolio_Agung\`
2. Buka **Laragon**, lalu klik tombol **Start All**
3. Akses via browser:
   ```
   http://localhost/Portofolio_Agung/
   ```
   *(Atau `http://portofolio_agung.test/` jika Pretty URL/Virtual Host aktif)*

### Menggunakan PHP Built-in Server
Jalankan perintah berikut di terminal:
```bash
php -S localhost:8000
```
Lalu buka browser di `http://localhost:8000`.

## 🌐 Panduan Deploy ke GitHub Pages

1. Buat repository baru di GitHub bernama `portofolio` (atau `username.github.io`).
2. Hubungkan repositori lokal:
   ```bash
   git remote add origin https://github.com/USERNAME/portofolio.git
   git branch -M main
   git push -u origin main
   ```
3. Buka tab **Settings** di repo GitHub ➔ Pilih menu **Pages** ➔ Pada *Branch*, pilih `main` dan folder `/ (root)` ➔ Klik **Save**.
4. Website portofolio kamu akan aktif secara langsung di URL `https://USERNAME.github.io/portofolio/`!
